数据从哪来，存在哪

采集方式和保存位置，先说清楚

只读公开数据，不登录

软件读取 B站、YouTube 和各家热榜的公开接口，不需要也不会要求你登录平台账号。每次请求间隔至少 1.5 秒，遇到平台风控就立即停止，不硬抓。平台接口有变化时，个别功能可能暂时取不到数据。

数据保存在你自己电脑上

关键词、采集结果、报告和选题池都存在本机文件夹，位置可以在「设置」里改，卸载软件也不会删除。只有你主动使用「AI 选题」并填了 Key 时，当天的汇总数据才会发送给你选的 AI 服务。

AI 选题：没有 Key 也能用「复制提示词」，粘贴到任意 AI 网页

安装与使用

第一次用，照这三步来

三步开始使用

1. 下载安装包并核对校验值，安装（不需要管理员权限）。
2. 在「新热点发现」里换成你自己赛道的关键词，点「一键发现新热点」。
3. 在「对标账号」加几个同行，打开「每日自动采集」，以后每天看报告就行。

支持 Windows 电脑

当前安装包适用于 Windows 10 / 11（64 位），不能装在手机或 Mac 上。

安装包签名与文件校验

当前安装包未做代码签名，Windows 或安全软件可能提示风险。本页提供 SHA-256 校验值及 PowerShell 核对方法，请自行判断是否继续。

下完可以核对一下文件

在下载目录里按住 Shift 右键，选「在此处打开 PowerShell 窗口」，粘贴这条回车：

Get-FileHash .\BlueWhaleRadar_Setup_v0.6.3.exe -Algorithm SHA256

出来的那串应该和下面这串一模一样：

常见问题

开始之前你可能想知道

  • 要钱吗？要登录我的 B站 / 抖音吗？

    软件免费使用，不需要登录任何平台账号。只有「AI 选题」想一键出结果时，需要你自己去 DeepSeek、通义千问、Kimi 或 OpenAI 申请 Key，费用按该服务的价格；不想用 Key，就点「复制提示词」粘贴到 AI 网页。

  • 每日自动采集，要一直开着软件吗？

    不用。它交给 Windows 任务计划程序定时运行，软件关着也会跑。到点时电脑关机或睡眠，会在下次开机后补跑；下次打开软件，顶部会提示这次采集的结果。

  • 某个关键词今天搜出来是 0 条？

    可能是平台临时限流或接口变化，软件遇到风控会主动停下，不会反复请求。通常过一段时间或第二天就恢复；如果一直是 0，请到 GitHub 发行页反馈。

  • 怎么更新到新版本？

    软件每次打开会检查一次新版本，有更新时弹出提示，点「立即更新」即可。也可以随时回到本页或 GitHub 发行页下载最新安装包。
