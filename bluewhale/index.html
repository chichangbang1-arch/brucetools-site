三步开始使用

1. 下载安装包并核对校验值。
2. 启动蓝鲸，粘贴你有权保存的视频链接。
3. 按需在「平台授权」登录，再添加下载任务；下载文件保存在电脑上。

支持 Windows 电脑

当前安装包适用于 Windows 10 / 11（64 位）。

安装包签名与文件校验

当前安装包未做代码签名。本页提供 SHA-256 校验值及 PowerShell 核对方法。如果安全软件拦截，请自行判断是否继续。

下完可以核对一下文件

想确认文件没被篡改，在下载目录里按住 Shift 右键，选「在此处打开 PowerShell 窗口」，粘贴这条回车：

Get-FileHash .\BlueWhaleDownloader_Setup_v3.3.14_preview_20261113n.exe -Algorithm SHA256

出来的那串应该和下面这串一模一样：

bfd8c2101bb9914f1a1be9aa6efffc72de329db49f3578fe7227b4acc76048be

常见问题

用户问得最多的四个

  • 要钱吗？会不会偷偷上传我的东西？

    当前版本免费使用。解析和下载会连接对应平台，检查更新会连接更新服务器；持久化的平台授权信息使用 Windows 用户加密方式保存在本机。本站不要求你上传授权文件。

  • 点「平台授权」没反应，浏览器起不来

    授权功能会寻找本机 Edge 或 Chrome。自 3.3.11 起，浏览器均不可用时会给出明确提示。若两者均不可用，请按错误提示检查浏览器是否安装；公司电脑也可能有管理策略限制，请联系管理员。

  • 下载失败，提示可能需要重新登录

    先到「平台授权」重新登录那个平台，再在浏览器里把这条视频播一遍，确认能正常播放，然后回软件重试。如果别的能下、只有这条不行，可能是该视频的访问或解析限制，请结合故障诊断信息进一步确认。

  • 怎么更新到新版本？

    软件会自己检查，有新版本时提示，点「立即更新」就自动下载安装并重启，不用再来这个页面。3.2.0 以下的老版本不支持自动更新，要重新下载安装包。
